# Implementation plans

Create one reviewed implementation plan before starting each development milestone.

The plan translates the user-visible milestone definition in `docs/development-milestones.md` into a concrete, dependency-ordered implementation approach. It is not a progress log and must not contain large amounts of transient work notes.

## Workflow

1. Copy `template.md` to `mN-short-title.md`.
2. Complete every section. Use `Not applicable` with a reason rather than silently removing sections.
3. Resolve decisions required before implementation or record them as explicit unresolved items.
4. Review scope and exclusions against the canonical milestone definition.
5. Split the accepted plan into implementation issues ordered by dependency.
6. Update the plan only when the intended design or scope changes materially.
7. Add the final completion demonstration procedure before closing the milestone.

Implementation issues should link back to the plan and must not independently expand milestone scope.
