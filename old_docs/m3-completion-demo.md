# M3 動画・チャット同期 完了デモ

M3「動画とチャットを同期して場面を探す」の完了確認手順です。

## CI fixtureで確認すること

`apps/web/e2e/m3-completion.spec.ts` は PostgreSQL、Main API、Python Worker、Web UI、YouTube Data Gateway を起動し、次を確認します。

- `metadata / chat_replay` の二工程収集
- チャットのDB保存と再収集時の重複防止
- YouTube埋め込みプレーヤーの表示
- チャット検索と検索結果からの時刻ジャンプ

## 実データで確認すること

1. 数時間規模の、チャットリプレイを利用できる終了済み配信を登録する。
2. 全工程収集を開始し、`metadata → chat_replay` の順に進んでJobが `succeeded` になることを確認する。
3. 配信詳細でYouTube埋め込みプレーヤーと収集済みチャットを表示する。
4. 先頭付近、中間、末尾のチャットからプレーヤーを該当時刻へ移動する。
5. 配信内検索で実在する語を検索し、検索結果から該当時刻へ移動する。
6. 同じ配信を再収集し、チャット件数が増加しないことを確認する。

## 記録

配信ID、実行日時、工程状態、チャット件数、検索語、確認した時刻を記録します。Cookie、APIキー、認証ヘッダー、チャット本文は記録しません。

CI fixtureだけでは実データ完了条件を満たしません。上記手順を実YouTube配信で完走した時点でM3完了とします。
