# ADR-0005: 動画・音声・字幕データの収集を廃止する

- Status: Accepted
- Date: 2026-08-08
- Supersedes: ADR-0003 の字幕収集・字幕同期・字幕検索に関する決定

## Context

字幕の取得・保存・検索は M3 で実装したが、取得可否や外部仕様差を扱うために Worker、YouTube Data Gateway、Main API、PostgreSQL、Web UI の全層へ大きな複雑性を持ち込んでいる。動画・音声ファイルの保存と独自文字起こしも将来構想に含まれていたが、現時点で想定する切り抜き候補探索の価値に対して取得・保存・解析コストが大きい。

今後の中心データは配信メタデータ、ライブチャット、およびチャットから導出する時系列指標と切り抜き候補とする。

## Decision

- 新規の手動収集と予約後収集は `metadata`、`chat_replay` の二工程とする。
- 字幕トラックと字幕セグメントの取得、保存、一覧、同期表示、検索を廃止する。
- 既存の字幕データは退避せず、forward migration で削除する。
- 移行時に未完了の `transcript` step が親 Job を停止させないよう、廃止済み step を終端化し、Job を二工程基準で再計算する。
- サーバーは動画・音声ファイルを取得、保存、artifact 化、解析しない。音声抽出、音声認識、音響特徴量解析も導入しない。
- 大容量ファイル保存を前提としないため Azure Blob Storage と FFmpeg を採用技術から外し、永続化先を PostgreSQL に限定する。
- YouTube IFrame API によるブラウザ内の埋め込み再生は維持する。これは動画ファイルの取得・保存ではなく、チャットの時刻を確認する閲覧機能である。
- YouTube Data Gateway はライブチャットリプレイ取得の境界として維持する。

## Consequences

- 字幕がないことや字幕だけ取得できないことを、`no_data`、部分失敗、利用者向けエラーとして扱わなくなる。
- 配信内検索と時刻範囲取得はチャット専用の契約になる。
- M3 は YouTube 埋め込みプレーヤー、チャット、チャット検索の時刻同期を完成価値とする。
- 字幕本文を使う将来の要約や分析は計画対象外となる。必要性が具体化した場合は、新しい要件とデータ取得方針を別の ADR で決定する。
- 適用済み migration と ADR-0003 は履歴として保持するが、現行方針には使用しない。

## Rollout note

この ADR の採択直後は実装と外部契約に旧字幕機能が残る。実装計画 `docs/implementation-plans/remove-media-and-transcript-collection.md` の順序で、ジョブ生成、旧 step の終端化、実行経路、読み取り契約、schema の順に段階的に除去する。
