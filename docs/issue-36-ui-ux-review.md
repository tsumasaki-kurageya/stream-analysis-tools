# Issue #36 UI/UX レビュー

## 対象

YouTube ストリームのプレビュー、登録済み動画の再選択、動画とチャットの同期探索、収集予約を行う Web UI を確認した。

## 反映した改善

- [x] ユーザー向け文言、状態、日時、空表示、エラーを日本語へ統一した。
- [x] API の英語 `detail` を直接表示せず、エラーコードから次の行動が分かる日本語へ変換した。
- [x] プレビュー履歴をブラウザへ最大8件保存し、URLを再入力せず再選択できるようにした。
- [x] トップバー、登録済み動画の左ペイン、動画の中央ペイン、チャットと収集の右ペインでワークスペースを構成した。
- [x] 詳細画面の動画とチャットを独立スクロールにし、ページ全体の縦スクロールを抑えた。
- [x] 左右ペインをキーボード操作可能なボタンで開閉できるようにした。
- [x] 狭幅では中央コンテンツを先に表示し、左右ペインを下へ安全に再配置した。
- [x] 長い動画タイトルとチャット本文を折り返し、省略が必要なライブラリ項目には完全なアクセシブル名を付けた。
- [x] ローディング、空状態、収集失敗、データなし、埋め込み再生不可の表示を維持した。
- [x] `header`、`main`、`nav`、`aside`、ラベル、`aria-live`、`aria-current`、フォーカス表示を整理した。
- [x] `prefers-reduced-motion` を尊重し、WCAG 2.2 AA を目標とする配色とフォーカスリングを維持した。

## UI ライブラリ

新しい UI ライブラリは導入していない。今回必要なペイン、状態表示、フォーム、レスポンシブ配置は既存の React と CSS で実現できるため、依存関係とバンドルサイズを増やす利点が小さいと判断した。既存コンポーネントを再利用し、追加のランタイム依存は 0 件である。

## 自動検証

- React Testing Library: 日本語ランドマーク、パネル開閉、プレビュー履歴、登録済み動画の切り替え、エラー翻訳、収集状態、検索・ページング。
- Playwright: 日本語UI、プレビュー履歴の再オープン、モバイルのパネル開閉、予約、収集の再試行、動画とチャットの同期シーク、キーボード検索、埋め込み不可時のフォールバック。
